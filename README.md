# Rogue

## Introduction

This project implements a console-based rogue-like game developed in Go, inspired by the classic 1980 game *Rogue*. It features procedural dungeon generation, turn-based combat, and a modular architecture separating domain logic from the presentation layer.

## Requirements

* **Go**: Version 1.21 or later
* **Library**: [tcell](https://github.com/gdamore/tcell)
